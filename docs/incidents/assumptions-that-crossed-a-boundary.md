# 우리가 정한 근거가 단계를 넘어오며 무효가 됐다 — 결함 2건 (2026-08-21)

**계열: 전제의 낡음.** 다만 낡은 것이 외부 API 가 아니라 **우리 자신의 근거**다.

`llm-api-schema-drift.md` 는 외부 계약을 기억으로 그렸다가 실측에서 어긋난 기록이다.
이번 둘은 반대다 — **실측으로 정한 값이었고, 그 근거가 다음 단계로 넘어오며 사라졌는데
아무도 다시 확인하지 않았다.**

두 건 다 **골든셋 측정이 아니었으면 몰랐다.** 단위 테스트도 통합 테스트도 통과했다.

---

## 결함 1 — SDK 예외가 우리 계약을 우회했고, **실패한 호출이 기록되지 않았다**

### 무엇이 일어났는가

4단계 골든셋 15건 측정의 1차 실행이 `case-007` 에서 죽었다.

```
anthropic.APIConnectionError: Connection error.
  File "src/regchange/pipeline/grounding.py", line 148, in verify
    result = await self._llm.complete(
```

측정은 6건에서 중단됐다. 그것만이면 재실행하면 되는 일이다. **문제는 그 호출이
`llm_invocation` 에 남지 않았다는 것이다.**

### 왜 남지 않았는가

`pipeline/grounding.py` 와 `pipeline/obligations.py` 는 실패를 이렇게 다룬다.

```python
except LLMError as exc:
    await self._record(InvocationRecord(outcome=InvocationOutcome.ERROR, ...))
    raise
```

`LLMError` 는 **우리 계약**이다 (`adapters/llm/base.py`). 그런데 어댑터
(`adapters/llm/claude.py`)가 SDK 예외를 그 계약으로 옮기지 않았다. `APIConnectionError`
는 `LLMError` 가 아니므로 `except` 를 지나쳐 파이프라인 밖으로 나갔고, 기록 코드는 실행되지
않았다.

### 왜 이것이 사건인가

마이그레이션 010 이 이렇게 적었다.

> **호출이 실패한 경우에도 행을 남긴다.** `outcome` 이 그것을 구별한다. 실패한 호출이
> 기록되지 않으면 **"실패한 날"과 "호출하지 않은 날"이 같은 부재가 된다.**

그 방어가 스키마와 파이프라인에는 있었는데 **어댑터 경계에서 새고 있었다.** 우리가 정의한
예외 계층 안에서만 성립하는 방어였고, 그 계층 밖의 예외는 그냥 지나갔다.

### 3단계에도 있던 결함이다

`pipeline/obligations.py` 의 같은 구조가 3단계부터 있었다. 그때 드러나지 않은 이유는
**네트워크가 끊기지 않았기 때문**이다. 기준선 §1 의 "호출 실패 0건"은 실패가 없었다는
사실이자, **실패를 기록할 수 있는지 확인하지 못했다**는 사실이기도 하다.

### 어떻게 발견되었는가

**골든셋 15건을 한 번에 돌렸기 때문이다.** 케이스 하나짜리 시험 실행에서는 확률이 낮았고,
100회 호출이 한 시간 동안 이어지자 한 번 끊겼다.

> 오래 도는 실행이 짧은 실행이 못 보는 것을 본다. 이 저장소가 매일 운영을 도는 이유와
> 같은 성질이다 (ADR-014).

### 고친 것

`ClaudeClient.complete` 가 `anthropic.APIError` 를 `LLMError` 로 옮긴다. 이제 네트워크
오류도 `ERROR` 행으로 남고, 파이프라인의 실패 처리 경로가 발화하며, 측정이 그 케이스만
이관하고 계속 돈다.

### 남는 것

- **끊긴 호출 1건의 기록은 복구되지 않는다.** 그 시각에 무엇을 보냈는지는 남지 않았다.
- 저장소 쓰기 실패나 DB 실패는 여전히 예외를 전파한다. 그것은 설계대로다 — 기록할 수
  없으면 결과도 쓰지 않는다.

## 결함 2 — `max_tokens` 8000 의 근거가 다른 단계로 넘어오며 사라졌다

### 무엇이 일어났는가

2차 실행에서 영향평가 초안이 `max_tokens` 에서 잘렸다.

```
응답이 JSON 이 아니다 — 출력이 max_tokens 에서 잘렸다:
  Unterminated string starting at: line 1 column 374
```

스키마 위반 재시도 2회 뒤 그 케이스는 `INSUFFICIENT_EVIDENCE` 로 이관됐다.

### 왜 8000 이었는가 — **그때는 근거가 있었다**

```python
MAX_OUTPUT_TOKENS = 8000
"""의무사항 추출 출력의 상한.

조문 하나에서 나오는 의무사항은 많아야 십수 건이고 각 항목이 짧다. 8000 은 그 몇 배로
둔 여유값이다."""
```

**근거가 「의무사항 추출」에 묶여 있었다.** 4단계가 같은 클라이언트로 영향평가 초안을
호출하면서 그 근거는 무효가 됐다 — 필드가 많고(영향 문단·통제항목·부서 근거·증빙),
`thinking` 이 출력 토큰에 계상된다. 관측된 성공 초안이 **7,848 토큰**이었으니 상한과의
여유가 152 토큰이었다.

**docstring 은 정확했고 아무도 다시 읽지 않았다.**

### 왜 이것이 사건인가

잘림은 파싱 실패로 **시끄럽게** 드러났다. 그 점은 설계대로다. 문제는 결과다.

> 그 케이스는 **모델 능력이 아니라 우리 상수 때문에** 근거 부족이 됐다.
> 그 상태로 측정하면 **지표가 우리 상수를 잰다.**

측정값이 측정 대상이 아닌 것을 재고 있는 상태이며, 그것을 모른 채 "모델이 근거를 못
찾는다"로 읽으면 다음 조치가 통째로 틀린다.

### 어떻게 발견되었는가

`llm_invocation` 의 `error_detail` 에 남은 문장이었다. 러너 화면에는
`INSUFFICIENT_EVIDENCE` 로만 보였고, **행을 열어야 이유가 보였다.**

```sql
SELECT error_detail FROM llm_invocation WHERE outcome = 'SCHEMA_INVALID';
```

**기록이 없었다면 "모델이 근거를 못 찾았다"로 끝났을 것이다.** ADR-013 이 LangGraph 채택
조건으로 이 기록을 건 이유가 여기서 값을 한다.

### 고친 것

- 상한을 **16000** 으로 올렸다. 관측된 성공 출력의 2배이며 비스트리밍 요청의 권장
  기본값이다. docstring 에 **왜 8000 이었고 무엇이 그 근거를 무효로 만들었는지**를 적었다.
- 러너 요약에 `verification_errors` 를 넣었다. 호출 실패로 이관된 케이스가 있으면
  **측정이 오염됐다는 경고가 화면에 뜬다.**

### 남는 것

16000 도 근거가 하나의 관측(7,848)이다. 영향 문단이 더 많은 개정에서 다시 부딪힐 수
있으며, 그때는 **또 잘림으로 드러난다** — 조용히 나빠지지는 않는다.

## 두 결함의 공통 기전

| | 결함 1 | 결함 2 |
|---|---|---|
| 무엇이 낡았나 | 예외 계층의 **범위** | 상수의 **근거** |
| 언제 정해졌나 | 3단계 | 3단계 |
| 왜 그때는 맞았나 | 우리가 던지는 예외만 있었다 | 추출 출력만 있었다 |
| 무엇이 바꿨나 | 실제 네트워크 실패 | 더 큰 출력을 내는 새 단계 |
| 왜 조용했나 | 예외가 계층 밖이라 기록 코드가 안 돌았다 | 화면에는 `INSUFFICIENT_EVIDENCE` 로만 보였다 |

**둘 다 "이 근거가 여기서도 유효한가"를 묻지 않아서 생겼다.** 단계를 넘길 때 코드는
그대로 가져오면서 그 코드가 서 있던 **전제**는 가져오지 않았다.

### 그래서 무엇을 할 것인가

- **상수 docstring 에 「무엇을 기준으로 정했는가」를 적는다.** 이미 규약이다 (CLAUDE.md §4).
  이번에는 그 규약이 지켜졌고 **읽히지 않았다.** 규약이 지켜져도 읽히지 않으면 소용없다는
  것이 이번 교훈이며, 그래서 새 단계가 기존 상수를 재사용할 때 **그 docstring 을 인용해
  유효성을 적는 것**을 관례로 삼는다.
- **외부 라이브러리의 예외를 우리 계약으로 옮기는 것을 어댑터의 책임으로 못박는다.**
  `adapters/llm/base.py` 의 계약에 그 문장이 없었다. 지금은 있다.
