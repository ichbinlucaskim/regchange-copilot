## 2. 지표

**표는 `docs/23-metrics-summary.md` §1 에 있다.** 여기에는 그 표에서 반드시 함께 읽어야
하는 세 문장만 옮긴다.

1. **인용 정확도 1.0000 은 성적이 아니라 항등식이다.** gate 2단이 실재하지 않는 ID 를
   폐기하므로 담당자에게 도달한 출력에서 이 값은 언제나 1.0000 이다. 이 문서의 이전 판이
   §2 주석에 "원칙 2가 작동하면 이 값은 100%여야 한다"고 적었고, 그 예상이 맞았다.
2. **「인용 폐기 0건」은 추출 단계의 사실이지 영향평가 단계의 사실이 아니다.**
   영향평가에서는 4단계 1건 · 변동성 회차3 1건 · 42건 4건이 발화했고 **전부
   `QUOTE_NOT_FOUND`** — gate 가 「가장 위험한 형태」로 정의한 항목이다 (`docs/23` §1.4).
3. **영향 문단 재현율 0.3208 은 목표 0.85 에 0.53 미달이다.** 축소하지 않는다.
4. **F-6 은 사람 판정 20건에서 관측되지 않았다(0.0000).** 95% 상한이 **0.168** 이고,
   **알려진 F-6 사례(case-013)가 이 표본 안에서 이 척도를 통과했다** — 척도가 묻는 것은
   「인용이 주장을 받치는가」이지 **「그 인용을 했어야 하는가」가 아니다** (`docs/23` §2.8).

## 3. 실패 사례 분석

**원인을 넷으로 가른다.** "모델이 부족해서"로 끝내지 않는다.

### 3.1 검색이 못 찾았다 — (a)

42건에서 정답 문단 50개 중 **0.46 이 검색 13건 밖**이었다(`docs/21` §2). 신규 27건에서만
보면 0.71 이다 — 명시적 법령 인용이 없고 어휘가 다른 조항을 의도적으로 늘린 결과다.

- **정책 계층 조항은 문단 유사도로 잡히지 않는다** → **R-22**. 위임 승격으로 3항목 중
  1항목을 회수했고, 나머지 2항목은 후보를 18조로 좁혀도 7·8위였다. **더 강한 근거가
  된 실패다** — 검색 파라미터로 고칠 문제가 아니다.
- **빈 위임 조항이 안 잡힌다** (case-025, `ISP-GUIDE-003#31`). 본문이 짧아 어휘 밀도가
  낮고, 법령 어휘를 그대로 쓰는데도 밀린다.
- **질의 구성이 검색을 크게 바꾼다** (case-023). 개정된 두 호가 292자인데 조립본 전문
  6,944자로 질의하면 나머지 6,651자의 정의 조항이 질의를 끌고 간다. **n=1 이다.**

### 3.2 검색은 찾았는데 LLM 이 안 골랐다 — (b)

기존 15건에서 0.42 다. **이것은 버그가 아니라 설계한 교환이다** — 같은 42건에서 검색
단독은 재현율 0.60 / 정밀도 0.114 이고 LLM 을 얹으면 0.3208 / **0.625** 가 된다
(`docs/23` §7.1). F-6 을 F-1 보다 비싸게 본 손실함수의 결과이며, **그 대가가 재현율
0.28 이라는 것이 이 단계에서 두 번째로 확인됐다.**

### 3.3 근거 인용문이 원문에 없어 코드가 지웠다

case-008(42건)에서 gate 2단이 **4건을 폐기했고 부서 배정이 통째로 사라졌다.**
**부서 재현율 0.4750 의 일부는 「배정을 못 한 것」이 아니라 「배정의 근거가 원문에 없어
지워진 것」이다.** 두 실패는 조치가 다르고, 지금까지 한 칸에 섞여 있었다.

부서 이름 자체가 자유 텍스트라 회차마다 다르게 쓰인다 → **R-24**.

### 3.4 판정이 불안정하다

같은 개정을 두 번 넣으면 다른 답이 나온다 → **R-27**. 케이스 단위로 15건 중 10건이
흔들리고, 흔들리는 층이 정해져 있다 — `hit`(무엇을 찾는가)은 안정적이고
`impact_status`·`departments`(어떻게 판정하고 누구에게 배정하는가)가 흔들린다.

**case-013 은 흔들리지 않고 일관되게 틀린다.** 3회 전부 놓쳤고 42건에서도 놓쳤다.
문단이 실재하고 인용문도 원문 그대로인데 의미가 어긋난 경우이며, **gate 2단도 3단도
잡지 못한다.** 이것이 F-6 의 실물이다.

**그리고 사람 판정도 이 척도로는 잡지 못했다.** case-013 의 인용은 판정지 16행에 있고
사람이 `SUPPORTED` 로 봤다 — 주장이 문단을 정확히 서술하기 때문이다. **틀린 것은 서술이
아니라 그 문단을 인용했다는 것 자체다.** 척도가 그 질문을 묻지 않는다 (`docs/23` §2.8).

### 3.5 적대적 입력에 한 번 뚫렸다

adv-011 — 가짜 대화 이력을 **항 안쪽**에 심었을 때 스캐너가 놓쳤고 모델이 따랐다.
두 문제를 나눠 등재했다: 스캐너 `^` 앵커는 **R-28**, 격리 구조가 뚫린 것은 **R-29**.
**모델 출력은 오염됐으나 시스템은 아무것도 실행하지 않았다** — 승인 게이트 앞에서 멈춘다.

## 4. 이 평가가 측정하지 못한 것

1. **「그 인용을 했어야 하는가」를 재는 척도.** F-6 사람 판정 20건은 끝났고 값은
   0.0000(상한 0.168)이다. 그러나 **그 척도는 case-013 을 통과시켰다** — 인용이 주장을
   정확히 서술하되 **그 문단을 인용한 것 자체가 실패**인 경우를 잡지 못한다.
   **가장 큰 빈칸이 「값이 없다」에서 「재는 방법이 없다」로 옮겨졌다** (`docs/23` §2.8).
   덧붙여 gate 3단이 `PARTIAL`·`UNSUPPORTED` 로 본 31건은 사람이 보지 않았다.
2. **실제 은행 규정.** 코퍼스 5종 152조는 **합성**이다. `docs/21` §7 이 인용 밀도를
   외부 데이터와 대조했지만 그 대리 지표에도 한계가 있다(§7.7). **실물 표본은 이
   저장소의 범위 밖이다.**
3. **42건에서의 재현성.** 1회만 돌렸다. 케이스 단위 불안정 비율이 표본 확대 후 어떻게
   되는지는 미측정이다.
4. **적대적 강도의 위쪽.** 다단계 대화, 인코딩 변형, 대량 반복, 우리 프롬프트 문구
   흉내는 시험하지 않았다(`docs/18` §4.3). **인용 날조 시도 0건은 「날조하지 않는다」가
   아니다** — 분모가 0 인 지표는 지표가 아니다.
5. **`EFFORT` 를 낮췄을 때 무엇이 일어나는가.** 미측정이며 왜 지금 안 재는지는
   `docs/23` §5 에 있다.
6. **승인이 형식화되는 현상.** 담당자가 검토 화면을 얼마나 실제로 읽는지는 측정 수단이
   없다. 이 시스템이 만드는 가장 큰 위험이 이것일 수 있으며, **재지 못한다는 사실을
   적어 두는 것 외에 지금 할 수 있는 것이 없다.**
7. **운영 기간.** 일일 수집은 2026-08-20 부터 돌지만 **영향평가 경로는 운영에서 돈 적이
   없다.** 골든셋 위의 값이다 (축 3).

## 5. 결론 — 어디까지 믿어도 되는가

### 5.1 믿어도 되는 것

| 무엇 | 왜 |
|---|---|
| **인용된 문단 ID 가 실재한다** | 코드가 강제한다. 항등식이며 `tests/security` 가 우회 경로가 없음을 검사한다 |
| **승인 없이는 아무것도 나가지 않는다** | 그래프 구조 · DB 권한 · FK 세 겹. 무너지는 방식이 다르다 (ADR-018) |
| **영향 없음을 영향 없음이라 말한다** | 42건에서 타법개정 11/11, 영향 없음 전체 20/22. **베이스라인은 기권 자체가 구조적으로 불가능하다** |
| **제안이 적고 그중 대부분이 맞다** | 케이스당 주장 0.48건, 정밀도 0.625, decoy 인용 1 |
| **검색은 재현된다** | 3회 완전 일치, 편차 0 |

### 5.2 믿으면 안 되는 것

| 무엇 | 왜 |
|---|---|
| **이 시스템이 영향 문단을 빠짐없이 찾는다** | 재현율 0.3208. **셋 중 둘을 놓친다.** 담당자는 이 출력을 **후보**로 읽어야 하고 전수 검토를 대신하지 못한다 |
| **인용이 주장을 뒷받침한다** | 20건 전수 사람 판정에서 `UNSUPPORTED` 0건이나 **95% 상한이 0.168** 이다. 그리고 이 척도는 「인용했어야 하는가」를 묻지 않아 **case-013 을 통과시켰다** |
| **같은 개정에 같은 답이 나온다** | R-27. 케이스 단위로 흔들리고, 흔들리는 것이 판정과 부서 배정이다 |
| **부서 배정을 그대로 쓸 수 있다** | R-24. 자유 텍스트이고 조직도와 대조되지 않는다 |
| **인젝션을 막는다** | 차단율 0.9412. **뚫린 자리가 하나 있고 원인의 절반은 미확인이다**(R-29) |
| **지표가 실무를 예측한다** | 코퍼스가 합성이고 골든셋 42건이며 원천이 편중돼 있다(IMPACT 20 중 15건이 두 원천) |

### 5.3 운영 투입 판단

**지금 상태로 「자동 제안」에 투입할 수 없다.** 투입할 수 있는 형태는 하나뿐이다.

> **담당자가 어차피 전수로 볼 개정에 대해, 후보와 근거를 먼저 보여 주는 보조 도구.**

이 형태에서는 재현율 0.3208 이 치명적이지 않다 — 놓친 것은 담당자가 원래 하던 방식으로
찾고, 시스템이 더한 것은 **먼저 볼 곳을 좁혀 주는 것**이기 때문이다. 반대로 「시스템이
찾지 않은 것은 영향이 없다」로 읽히는 순간 이 수치는 그대로 사고가 된다.

**그 경계를 지키는 것은 문구가 아니라 구조다.** 승인 게이트가 그래프 레벨에 있고
(원칙 4), 기권이 구조적으로 가능하며(`INSUFFICIENT_EVIDENCE`), 근거 없는 제안이
코드로 폐기된다(원칙 2). 세 가지가 이 판단의 전제다.

**다음 단계에서 먼저 해야 할 것 셋:**

1. **「그 인용을 했어야 하는가」를 재는 척도를 만든다.** F-6 판정은 끝났고, 그 결과가
   **척도의 사각을 실물로 보여줬다**(13·16행). 함께 판정 기준의 **상한**도 정한다 —
   이번 기준은 하한만 고정돼 있어 불일치율이 0.05 와 0.40 사이에서 갈렸다
2. **목표를 손실함수와 정합하게 다시 세운다** — 재현율 0.85 는 「재현율을 깎아 정밀도를
   얻는다」는 설계를 반영하지 않은 목표다. ADR 로 남긴다 (`docs/23` §7.1)
3. **R-29 의 원인을 확인한다.** n=1 로 구조를 바꾸지 않되, 원인을 모른 채 두지도 않는다
