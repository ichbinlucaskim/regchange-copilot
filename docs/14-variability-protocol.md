# 14. 변동성 측정 규약 — **측정 전에 고정한 판정 기준**

**작성 시각**: 2026-08-22, **첫 실행 이전**.
이 문서를 쓴 뒤에 러너를 돌린다. 결과를 보고 이 문서를 고치면 그 사실을 §6 에 남긴다.

---

## 1. 왜 이 측정이 먼저인가

지금까지의 모든 대조가 **1회 실행**이다. 그리고 변동성이 0 이 아닌 것은 이미 안다 —
같은 (주장, 인용문) 쌍에 다른 판정이 나왔고(§5.3), case-013 이 단건 실행에서는 잡혔는데
전량에서는 놓쳤다(§12.3). **크기를 모른다.**

크기를 모르면 "0.8167 vs 0.7667" 같은 문장이 사실인지 잡음인지 말할 수 없다.

---

## 2. 무엇을 반복하는가 — **두 경로를 따로 잰다**

`docs/12-impact-assessment-results.md` §1-1 은 KURE 채택과 HYBRID 채택을 「변동성이
차이보다 작다는 가정 위에 있는 결론」으로 분류했다. **이 분류를 먼저 검증한다.**

두 경로는 성질이 다르다.

| 경로 | 무엇이 흔들릴 수 있나 | 반복 비용 |
|---|---|---|
| **검색** (임베딩 → BM25 → RRF) | 샘플링이 없다. 흔들릴 이유가 구조적으로 없다 | 0 (로컬) |
| **LLM** (추출 → 초안 → 검증) | `temperature`/`seed` 를 대상 모델이 거부한다 | 실비 |

**검색 경로가 정말 결정론적인지 확인하지 않고 단정하지 않는다.** 부동소수 연산, 배치
크기, 라이브러리 버전에 따라 임베딩이 흔들릴 여지가 이론적으로 있고, 무료이므로 재면 된다.

- **1a. 검색 반복 3회** — `retrieval_eval --embed kure-v1 --mode all`
- **1b. LLM 반복 3회** — `impact_eval --model sonnet` (현행 설정: anchored, `MAX_REVISIONS=0`)

1a 가 완전히 같은 결과를 내면 **KURE·HYBRID 채택은 변동성 문제가 아니다.** 그 결론들의
실제 취약점은 다른 것(표본 15건)이며, 그것은 §4 골든셋 확장이 답한다.

## 3. 측정 지표

### 3.1 집계 지표 — 회차 간 **최대−최소**

| 지표 | 4단계 값 |
|---|---|
| IMPACT 근거 확보 (/10) | 8 |
| IMPACT 정답 적중 (/10) | 8 |
| EMPTY 이관 (/3) | 2 |
| 부서 재현율 | 0.70 |
| gate 3단 판정 분포 (S/P/U) | — |
| 이관 건수 (/15) | 5 |

### 3.2 케이스 단위 불안정 — **이것이 가장 중요하다**

집계값은 상쇄된다. case-A 가 좋아지고 case-B 가 나빠지면 합계는 그대로다.
그래서 **케이스마다** 3회의 결과가 같은지 본다.

한 케이스가 **불안정**하다고 판정하는 조건 (셋 중 하나라도 회차 간 다르면):

1. `impact_status` (OK / NEEDS_REVIEW / INSUFFICIENT_EVIDENCE)
2. 정답 적중 문단 집합 (`hit`)
3. 부서 집합 (`departments`)

인용 문단 **전체**(`cited`)가 아니라 정답 적중(`hit`)을 쓰는 이유: decoy 를 하나 더
인용했다 뺐다 하는 것은 성능 변동이지 판정 변동이 아니다. 둘 다 세되 판정 기준은
`hit` 으로 한다. `cited` 편차는 참고값으로 함께 보고한다.

## 4. 판정 기준 — **지금 고정한다**

### 4.1 전역 기준

| 조건 | 판정 |
|---|---|
| 케이스 단위 불안정 **≤ 1건** (15건 중) **그리고** IMPACT 적중 편차 **≤ 1건** | **지금까지의 결론이 유지된다.** §1-1 한계를 닫는다 |
| 그 밖 | **재검토한다.** 어느 결론이 흔들리는지 명시하고 재측정 계획을 세운다 |

### 4.2 왜 1건인가

이 저장소가 실제로 1건 차이로 뒤집은 결정이 있기 때문이다.

**`MAX_REVISIONS = 0` 의 대가가 정확히 "IMPACT 적중 9/10 → 8/10", 즉 1건이다.**
그 1건을 근거로 재작성을 껐다(§12.7). 편차가 1건을 넘으면 그 대가 계산이 잡음 안에
들어간다 — 그러면 "0 으로 두는 대가는 1건"이라는 문장이 성립하지 않는다.

즉 **1건은 임의의 숫자가 아니라 이 저장소가 이미 1건에 결정을 걸었다는 사실**에서 나온다.

### 4.3 결론별 개별 판정 — 차이 대 편차

전역 기준과 별개로, **결론마다** 그것이 근거로 삼은 차이를 관측된 편차와 견준다.

```
결론이 근거로 삼은 차이  >  관측된 편차   →  유지
결론이 근거로 삼은 차이  ≤  관측된 편차   →  재검토
```

| 결론 | 근거가 된 차이 | 어느 경로 |
|---|---|---|
| KURE-v1 채택 (ADR-015) | 재현율 0.05 (정답 항목 1~2개) | 검색 (1a) |
| HYBRID 채택 (ADR-016) | **동률** — tie-break 로 결정 | 검색 (1a) |
| 위임 승격 N=2 (ADR-017) | 재현율 0.7667 → 0.8167 | 검색 (1a) |
| 재작성 종료 (`MAX_REVISIONS=0`) | 새 근거 0/15 (이진 관측) | LLM (1b) |
| de-anchored 기각 | 적중 9 → 6 (3건), 부서 재현율 0.70 → 0.25 | LLM (1b) |

**동률로 결정한 HYBRID 는 이 부등식으로는 절대 유지되지 않는다** (0 > 편차 는 성립할 수
없다). 1a 가 완전 일치를 보이면 편차가 0 이고 `0 > 0` 도 거짓이므로, HYBRID 는 **변동성이
아니라 tie-break 규칙의 타당성 문제**로 재분류한다. 이것을 미리 적어 둔다 — 결과를 보고
"동률이니까 괜찮다"로 넘어가지 않기 위해서다.

## 5. 고정하는 실행 조건

- 모델 `claude-sonnet-5`, `GroundingMode.ANCHORED`, `MAX_REVISIONS=0`, 승격 켬
- `as_of=2026-02-01`, `k=10`, `HYBRID`, KURE-v1 (`docs/10-...-protocol.md` §3)
- 프롬프트·감도·임계값을 **한 글자도 바꾸지 않는다**
- 3회를 연속 실행한다. 회차 사이에 코드·데이터를 고치지 않는다
- 각 회차의 원본 JSON 을 `evals/results/` 에 남긴다. 집계는 그 파일들만 읽는다

**비용 예상**: 4단계 1회 $2.6333 이었고 `MAX_REVISIONS=0` 이므로 그보다 적다.
3회 합계 $8 미만을 예상한다. 초과하면 그 사실을 결과 문서에 적는다.

---

## 6. 이 문서의 수정 이력

**수정 없음.** 2026-08-22 측정을 마쳤고 §4 의 판정 기준을 고치지 않았다.

측정 결과는 `docs/15-variability-results.md`. 요약하면 **전역 기준은 「재검토」**
(케이스 단위 불안정 10건 > 1건)이고 **결론별 개별 판정은 전부 「유지」**다
(§4.3 의 부등식을 전부 통과했다).

기준을 고치고 싶은 순간이 있었다는 것을 적어 둔다 — 집계 편차가 전부 0~2 로 작게
나왔으므로 "케이스 단위 조건은 과했다"고 말할 여지가 있었다. **고치지 않은 이유는
그 조건이 없었다면 10건이 흔들린다는 사실을 보고서에 쓰지 않았을 것이기 때문이다.**
기준이 잡아낸 것이 바로 기준을 두었던 이유다.
