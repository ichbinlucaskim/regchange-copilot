# 03. 데이터 분류

## 이 문서의 목적

이 시스템이 다루는 데이터를 민감도로 분류하고, 각 등급이 **어디까지 갈 수 있는지**를
정한다. 특히 "모델 공급자에게 전송해도 되는 데이터"의 경계를 명시한다. 이 경계를 문서로
정하지 않으면 프롬프트를 만드는 사람이 매번 즉석에서 판단하게 되고, 판단은 시간이 지나며
느슨해진다.
